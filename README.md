# SVG 路径实验室

解析 SVG 路径（M/L/H/V/C/S/Q/T/A/Z，绝对+相对），计算长度/切线/法线，
实现沿路径运动、路径变形、路径裁剪与控制点可视化。

## 运行

```bash
python3 -m http.server 8000   # 或任意静态服务器（ES Module 需要 http 协议）
# 打开 http://localhost:8000
```

## 测试

```bash
node test/path.test.mjs   # 25 项单元测试
```

## 技术架构

- **SVG**：渲染原始路径、裁剪结果、运动物体（切线决定朝向）
- **Canvas**：叠加层绘制控制点、控制柄、切线（蓝）、法线（绿）、裁剪端点
- **Web Worker**（`js/pathWorker.js`）：解析+扁平化+长度表在后台线程完成，
  长路径不阻塞 UI；Worker 不可用时自动回退主线程
- **PerformanceObserver**（`js/perfMonitor.js`）：观察 longtask + 滑动窗口帧率，
  FPS 持续低于 45 自动降级（放大扁平化容差 → 直线近似、变形采样 256→64 点），恢复后自动升回
- **IndexedDB**（`js/storage.js`）：路径存档的保存/读取/删除

## 核心模块

| 文件 | 职责 |
|---|---|
| `js/pathParser.js` | 词法/语法分析，规范化绝对指令段，错误带位置信息且不中断解析 |
| `js/pathGeometry.js` | 弧线端点→圆心参数化（含半径自动放大）、自适应细分、长度表、pointAtLength、裁剪、重采样、插值 |

## 已覆盖的边界情况

- 语法错误：未知指令 / 参数不足 / 非 M 开头 / 空路径，均给出带位置的提示
- 弧线：半径为 0 退化直线、半径不足按规范 F.6.5 放大、大弧/扫掠标志、旋转角
- 闭合路径 Z、相对指令、隐式重复指令、S/T 控制点反射
- 长路径：2000 段曲线扁平化约 15ms，且在 Worker 中执行
- 降级：低帧率自动切换直线近似，可手动切换
